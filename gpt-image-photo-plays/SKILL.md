# GPT-Image 2.5 照片出片

## 概述

这些玩法依赖 GPT-Image 2.5 的局部编辑：指哪打哪，画面其余部分保持不动。提示词原文在 [references/prompts.md](references/prompts.md)，来自卡兹克、AIZ小朱的文章《我整理了GPT-Image 2.5的12种玩法，希望能承包你的整个假期朋友圈。》（https://mp.weixin.qq.com/s/WeWYRyyAJtdPrErIV7063A）。

复制对应条目。只替换该条「槽位」里点名的专名、张数、颜色或英文单词。约束句原样保留，尤其是「完全不变」「只处理这一处」「除此之外的一切全部不变」。

## 步骤

1. 从下表选一个玩法。用户没指定时，按照片内容只选一个最贴的，不要把十二条一起跑。
2. 读取 `references/prompts.md` 里该条提示词再使用。
3. 按该条「输入」安排上传顺序。图一、图二就是这个顺序。
4. 在 ChatGPT：新建对话，输入框左侧加号选「创建图像」（默认 Image 2.5），上传照片，粘贴提示词。当前环境若已有图像编辑工具，用同一提示词和同一图序直接编辑。
5. 好几处互不相关的修改（例如只改天空、只去掉某根绳子、只顺头发）走「定点评论」，不要合成一条整图重绘。

定点评论：照片上传后进入图片编辑，选「添加评论」，在目标位置各写一条只描述该处的修改。每条评论一件事。

## 常见错误

- 改写或删掉「其余不变 / 只改这一处」——局部编辑会变成整张重绘。
- 城市、物体、单词仍留着示例（广州、椅子、Chair、11 张）。槽位必须换成用户这次的目标。
- 图序和提示词里的「图一 / 图二」对不上。
- 美食飞溅时挡住脸、拆掉容器，或涂鸦时在物体上贴字而不是用文字本身构成物体。
- 用户只给了一张图，却套用需要两张以上参考图的玩法。先补图，或改选单图玩法。
